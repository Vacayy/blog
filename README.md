# juyeong.kim

개인 블로그 레포지토리입니다.

## 개발

[Astro](https://astro.build)로 만든 정적 사이트입니다.

```sh
pnpm install
pnpm dev
pnpm build
```

## 글

`src/content/posts/YYYY-MM-DD-<slug>.md`에 씁니다.

```md
---
title: 제목
description: 요약
date: 2026-11-11
---
```
